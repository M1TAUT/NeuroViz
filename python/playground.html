Сервер не запущен

Нейросеть считается на Python, поэтому странице нужен сервер. Запусти его в терминале из папки проекта:

python3 python/server.py

Потом открой http://localhost:8000 и вернись сюда. Если открыть файл двойным кликом, работать не будет: адрес должен начинаться с localhost, а не с file://
