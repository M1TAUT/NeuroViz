Нейронная сеть:
как машина учится узнавать

Внутри нейросети нет записанных правил. Есть только числа, которые она подбирает сама, раз за разом сравнивая свой ответ с правильным. Здесь этот процесс видно целиком — от случайного шума в начале до работающего распознавания.

Эта версия работает сама по себе. Ничего запускать не надо, интернет не нужен — открывай двойным кликом хоть с флешки. Вся математика написана на JavaScript и считается прямо в браузере.

Как это устроено внутри
playground.html

Сеть внутри страницы. Прямой проход, обратное распространение и градиентный спуск лежат прямо в теге <script> — ищи функции forward, backward и applyGrads.

digits.html

Сеть и данные вместе. 3000 обучающих картинок MNIST вшиты в файл строкой base64 — отсюда его размер. Поэтому он и работает без интернета.

nn-from-scratch.js

Та же математика без интерфейса. Сто пятьдесят строк с подробными комментариями, запускается node nn-from-scratch.js. Учится решать «исключающее ИЛИ» — самую маленькую задачу, которую невозможно решить без скрытого слоя.

titul.html

Титульный лист и описание проекта. Открыть и нажать «Печать / сохранить в PDF».

Ни одной библиотеки: ни машинного обучения, ни вообще какой-либо. Вся математика — обычные циклы по массивам чисел. Рядом лежит вторая версия этого же проекта, где сеть вынесена на Python.
