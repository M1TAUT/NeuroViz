# Нейронная сеть: как машина учится узнавать

Школьный проект. Внутри нейросети нет записанных правил — есть только числа,
которые она подбирает сама, раз за разом сравнивая свой ответ с правильным.
Здесь этот процесс видно целиком.

**В папке две версии одного и того же проекта.** Они выглядят одинаково и
делают одно и то же — разница в том, где считается математика.

---

## Какую брать

| | `standalone/` | `python/` |
|---|---|---|
| Где считается сеть | в браузере, на JavaScript | на Python, на сервере |
| Что нужно для запуска | ничего | Python + numpy |
| Как открыть | двойной клик по `index.html` | сначала запустить сервер |
| Работает с флешки | да | только если там есть Python |
| Интернет | не нужен | не нужен |

**Для защиты бери `standalone/`.** Он открывается двойным кликом на любом
компьютере, ничего не просит и не может подвести. Школьный компьютер без
Python ему не помеха.

**`python/` — чтобы показать архитектуру.** Это та схема, по которой
устроены настоящие проекты: модель на Python, интерфейс на JavaScript,
между ними HTTP. Хороший ответ на вопрос «а как это делают по-взрослому».

Математика в обеих версиях одна и та же, просто записана на разных языках.

## Запуск

**Простая версия:**
```
standalone/index.html   →   двойной клик
```

**Версия с Python:**
```bash
cd ~/Desktop/NeuroViz/python

```
Потом открыть **http://localhost:8000**

Нужен numpy: `pip install numpy`

Двойным кликом версия с Python не работает — странице нужен сервер, а по
адресу `file://` до него не достучаться. Она об этом честно предупредит.

## Что внутри обеих версий

**Игровая сеть** (`playground.html`). Точки двух видов на плоскости, которые
надо научиться различать. Каждый нейрон нарисован не кружком, а собственной
картой: видно, какую область плоскости он выделяет. Сеть можно менять на
ходу — добавлять слои и признаки, включать шум, — и даже подёргать мышкой.

**Распознавание цифр** (`digits.html`). Обучается на настоящем человеческом
почерке (MNIST). Нарисуй цифру мышью и посмотри, узнает ли. Рядом видно, что
именно сеть разглядела в рисунке, и что выучил каждый нейрон первого слоя.

**Титульный лист** (`titul.html`). Для учителя: титульник и описание проекта
без технических подробностей. Открыть и нажать «Печать / сохранить в PDF».

## Где хранится обученная сеть

**Нигде на диске.** Файла с моделью не существует, и это не упущение.

Веса — обычный массив чисел в оперативной памяти. В простой версии они живут
в браузере, в серверной — в питоновском процессе. Закрыл вкладку или убил
сервер — сеть исчезла, при следующем запуске создаётся заново случайной.

Поэтому перед показом надо не «загрузить модель», а просто нажать пуск:
цифры обучаются за пару секунд.

> Если спросят «где ваша обученная модель» — ответ: модель это около десяти
> тысяч чисел, они пересчитываются с нуля за секунды, хранить их незачем.

## Как показывать · сценарий на 10 минут

Смысл в том, чтобы каждый шаг отвечал на вопрос, созданный предыдущим.
Не переключай всё подряд — веди историю.

**1. Покажи, что задача решается.**
`два пятна` · признаки X₁ X₂ · 0 скрытых слоёв → 100% за секунду.
> «Сеть умеет ровно одно — провести прямую. Здесь этого хватило.»

**2. Сломай это.**
`кольцо в кольце`, слоёв по-прежнему 0 → точность встаёт около 50%.
> «Никакая прямая не отделит внутреннее кольцо от внешнего.»

**3. Почини руками.**
Кликни признаки `X₁²` и `X₂²` → решает мгновенно, слоёв всё ещё ноль.
> «Мы подсказали, что важно расстояние от центра. Так делали до нейросетей.»

**4. Почини сетью — главный момент.**
Выключи `X₁²` и `X₂²`, добавь 1 скрытый слой на 4 нейрона → снова решает.
> «Никто не говорил сети про расстояние от центра. Она собрала этот признак
> сама. Вот за что нейросети и ценят.»

**5. Загляни внутрь.**
Поводи мышью по нейронам — наведённый разворачивается в большую карту справа.
В первом слое простые половинки плоскости, во втором из них сложены дуги.
> «Каждый по отдельности примитивный. Вместе получается кольцо.»

**6. Дай сложную задачу.**
`две спирали` · 3 слоя · признаки X₁ X₂ X₁² X₂² X₁X₂ · скорость 0.1.

**7. Покажи переобучение.**
`шум 30` · `обучающих 20%` · включи «показывать тестовые данные».
Сплошная линия ошибки падает, пунктирная разворачивается вверх.
> «Сеть перестала понимать закономерность и начала зубрить точки наизусть.»

**8. Вылечи.**
`регуляризация L2` · `коэффициент 0.03`, сброс и запуск заново.

**9. На десерт.**
Активация `Linear` — сеть перестаёт решать всё, кроме двух пятен.
> «Несколько линейных слоёв подряд — это снова просто прямая.»

И потяни нейрон мышкой — сеть тянется за ним и возвращается на место.

**10. Перейди к цифрам.** Пуск → пара секунд → рисуй цифру мышью.

## Что скорее всего спросят

**Это настоящая нейросеть?**
Да. Полносвязный перцептрон: входы, скрытые слои, выход. Обратное
распространение написано вручную, без TensorFlow и PyTorch.

**Что такое эпоха?**
Один полный проход по всем обучающим примерам. Внутри эпохи примеры идут
порциями — это размер батча.

**Почему линии ошибки две?**
Часть данных отложена и в обучении не участвует. Сплошная — ошибка на
знакомых примерах, пунктирная — на отложенных. Расхождение между ними и
есть переобучение.

**Почему Sigmoid учится медленнее?**
У неё пологие края: производная не больше 0.25, и при обратном
распространении сигнал затухает, пока доходит до первых слоёв. Это
классическая проблема затухающего градиента.

**Почему две версии?**
Браузер умеет выполнять только JavaScript — Python в нём не запускается.
Чтобы сеть была именно на Python, её приходится вынести на сервер. Простая
версия ценой языка получает независимость: работает где угодно без установок.

## Измеренные результаты

Всё прогнано, а не взято с потолка.

**Игровая сеть**, 400 эпох, скорость 0.1, сеть 4→2, признаки X₁ X₂:

| Набор | JS-версия | Python-версия |
|---|---|---|
| кольцо в кольце | 100% | 100% |
| исключающее ИЛИ | 100% | 99% |
| два пятна | 100% | 100% |
| две спирали | 82% | 83% |

Спираль с пятью признаками и тремя слоями за 900 эпох — **100%** в обеих.

**Распознавание цифр.** JS-версия: сеть 196→48→10, 3000 картинок, **92.3%**
на отложенной выборке. Python-версия: 196→64→10, 6000 картинок, **92–93%**.
Нарисованные мышью цифры узнают обе.

**Переобучение воспроизводится**: на шуме 30 и 20% обучающих разрыв между
ошибкой на обучении и на тесте +0.231, с регуляризацией L2 падает до +0.042.

**Скорость серверной версии**: один запрос (3 эпохи + карты + веса) — 2 мс,
ответ 17 КБ.

## Что легко сломать

**Нормализация рисунка в `digits.html`.** Функция `normalize()` обрезает
рисунок по краске, вписывает в квадрат 20×20 и центрует по центру тяжести.
MNIST подготовлен точно так же. Тронешь эти числа — распознавание
развалится, хотя обучение будет показывать прежние проценты.

**Диапазон пикселей.** В `mnist14.npz` они лежат как `uint8` 0..255, и их
обязательно надо делить на 255. С входами в сотни ReLU разносит суммы,
softmax насыщается, и сеть намертво застревает на 10% — на чистом
угадывании. Я на этом уже попался один раз.

**Строки `MN_TRAIN` и `MN_TEST`** в `standalone/digits.html` — упакованные
картинки в base64. Руками не редактируются: изменишь один символ —
рассыплется вся выборка.

**Физика графа.** Константа `K_LINK` подобрана замером на 0.07.
Выше 0.1 сеть начинает раскачиваться.

**Если страница тормозит** — скорее всего дело не в коде, а в отключённом
ускорении браузера. В Firefox и Zen проверяется в `about:support`, строка
Compositing: если там `software` или WebRender заблокирован, всё рисуется на
процессоре. Лечится флагом `gfx.webrender.all` в `about:config`. Быстрый
обходной путь — клавиша `P`.

## Как выложить в интернет

**`standalone/` можно выложить куда угодно** — это обычные статические файлы.

Тонкость: GitHub Pages умеет брать сайт только из корня ветки или из папки
`docs/`. Произвольную подпапку вроде `standalone/` он не примет. Поэтому
содержимое `standalone/` отправляем отдельной веткой `gh-pages`, где оно
окажется в корне:

```bash
cd ~/Desktop/NeuroViz
gh repo create NeuroViz --public --source=. --push

# standalone/ становится корнем ветки gh-pages
git subtree push --prefix standalone origin gh-pages

gh api -X POST repos/M1TAUT/NeuroViz/pages \
  -f "source[branch]=gh-pages" -f "source[path]=/"
```

Через минуту сайт будет на `m1taut.github.io/NeuroViz/`.

Когда поправишь что-то в `standalone/`, обновить так:

```bash
git add . && git commit -m "правки" && git push
git subtree push --prefix standalone origin gh-pages
```

**`python/` так выложить нельзя** — Pages раздаёт только статику и Python не
запускает. Для него нужен хостинг с Python: PythonAnywhere, Render, или VPS
на Timeweb. Для школьного проекта проще показывать его локально.

> На защите показывай с флешки, а не по ссылке. Школьный вайфай подводит
> чаще, чем хостинг.

## Куда учиться дальше

**1. Выжать свой же код** · один-два вечера
В конце `python/nn.py` и `standalone/nn-from-scratch.js` лежат пять опытов
с заранее прогнанными числами. Сделай все и сверься. Самый важный — убрать
нелинейность и увидеть, как все ответы схлопываются ровно в `0.500`.

**2. Та же математика чужими глазами** · неделя
- [neuralnetworksanddeeplearning.com](http://neuralnetworksanddeeplearning.com) — бесплатная книга Нильсена, главы 1–2
- [3blue1brown.com/topics/neural-networks](https://www.3blue1brown.com/topics/neural-networks) — лучшая визуализация backprop
- [github.com/karpathy/micrograd](https://github.com/karpathy/micrograd) — автодифференцирование в 100 строк

**3. Освоить NumPy как следует** · две-три недели
Разберись, почему `X @ W1` заменяет три вложенных цикла, и научись думать
формами массивов — это половина работы в машинном обучении.

**4. Настоящий инструмент** · месяц
PyTorch. Задание: тот же MNIST свёрточной сетью, 93% превратятся в 99%.
Учебник на русском: [education.yandex.ru/handbook/ml](https://education.yandex.ru/handbook/ml).
