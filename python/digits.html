Сервер не запущен

Нейросеть считается на Python, поэтому страница сама по себе ничего не умеет — ей нужен сервер. Запусти его в терминале из папки проекта:

python3 python/server.py

Потом открой http://localhost:8000 и вернись сюда. Если открываешь файл двойным кликом, страница работать не будет: адрес должен начинаться с localhost, а не с file://
